## What this repository is, in one paragraph

`chatgpt-cloud-elixir` solves a specific problem: restricted ChatGPT cloud
containers can execute native Linux binaries and inspect GitHub repos/workflows
through a connected interface, but often can't reach package registries or run
Docker. This repo manufactures portable, offline-capable Erlang/Elixir/Ash
runtime **capsules** via GitHub Actions, ships them as workflow artifacts, and
proves them `ALIVE` only via real local replay in the consuming container — CI
green is never treated as proof by itself. Alongside that, `control-plane/` is a
standing Phoenix/Ash service that projects OCEL process-intelligence evidence and
exposes an MCP (`/mcp`) surface, and `scripts/project_memory_proxy.py` +
`ChatGPTCloud.DfcmMemory` are two independent, protocol-compatible transports onto
a shared GitHub Project v2 board used as durable cross-agent memory. See
[`docs/explanation/architecture-overview.md`](explanation/architecture-overview.md)
for how these four pieces fit together as one system.
